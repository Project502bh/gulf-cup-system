# نظام إحصائيات كأس الخليج العربي

تطبيق ويب كامل (خادم + واجهة) لإدارة بطولات كرة القدم: البطولات، المنتخبات، اللاعبون،
المباريات، توليد دور المجموعات والأدوار الإقصائية تلقائيًا، والإحصائيات — مبني وفق
`PRD_Gulf_Cup_Statistics_System_AR.docx`.

## التشغيل

```bash
npm install
npm run seed   # تهيئة قاعدة بيانات تجريبية (مرة واحدة فقط، تُنشأ في data/gulf-cup.db)
npm start      # يشغّل الخادم على http://localhost:4310
```

لإعادة التهيئة من الصفر: احذف `data/gulf-cup.db` ثم أعد تشغيل `npm run seed`.

## التقنية

- **الخادم:** Node.js + Express، قاعدة بيانات SQLite عبر الوحدة المدمجة `node:sqlite`
  (لا تعتمد على أدوات بناء أصلية)، جلسات `express-session`، تشفير كلمات المرور بـ `bcryptjs`.
- **الواجهة:** HTML/CSS/JS خالص بدون أطر عمل أو خطوة بناء، وحدات ES مباشرة في المتصفح، RTL كامل.
- لا توجد تبعية على أدوات بناء أصلية (`node-gyp`)، لذا يعمل التثبيت مباشرة على أي جهاز لديه Node.js ≥ 22.5.

## القواعد الجوهرية المطبّقة من الوثيقة

- توليد دور المجموعات يتطلب مجموعتين بالضبط ومعتمدتين، وينشئ دوري من دور واحد لكل مجموعة.
- توليد نصف النهائي يتطلب انتهاء واعتماد **كل** مباريات المجموعات؛ يُطابق الفرق حسب الترتيب
  (نقاط ← فارق أهداف ← أهداف مسجلة) بالنمط أ1×ب2 و ب1×أ2.
- لا يقبل النظام تعادلًا في مباراة إقصائية: عند تساوي النتيجة يتطلب إدخال ركلات ترجيح حاسمة.
- إعادة طلب توليد مرحلة موجودة تعيد `409` عبر قيد فريد (`stage_locks`) على مستوى قاعدة البيانات،
  وليس فقط عبر تعطيل الزر في الواجهة.
- نتائج المباريات تمرّ بحالة "بانتظار الاعتماد" حتى يعتمدها مراجع النتائج أو مدير البطولة أو
  مدير النظام؛ الترتيب والتأهل يُحسبان من المباريات المعتمدة فقط.
- كل عملية حذف أو اعتماد أو توليد مرحلة تُسجَّل في سجل تدقيق (`/audit`، لمدير النظام فقط).
- الصلاحيات مطبّقة على مستوى الخادم (وليس فقط إخفاء الأزرار في الواجهة).

## قرارات مفتوحة (كما وردت في الوثيقة)

هذه النقاط نُفِّذت باجتهاد عملي قابل للتعديل، ولا تزال بحاجة لاعتماد رسمي من مالك المنتج:

- **كسر التعادل بعد النقاط وفارق الأهداف والأهداف المسجلة:** غير مطبَّق حاليًا (الترتيب يبقى
  حسب الاسم أبجديًا عند التساوي الكامل).
- **تحديد الفائز الإقصائي بعد التعادل:** طُبِّق عبر إدخال يدوي لنتيجة ركلات الترجيح.
- **قوالب البطولات:** النظام مبني افتراضيًا على قالب "مجموعتين بالضبط"؛ أي قالب آخر يحتاج تعديلًا.
- **إلزامية مباراة المركز الثالث:** تُنشأ تلقائيًا دائمًا مع النهائي حاليًا.
- **مزوّد الهوية والمصادقة متعددة العوامل:** طُبِّقت مصادقة أساسية بجلسات محلية فقط.
- **نشر الإحصائيات للجمهور مقابل الاستخدام الداخلي:** النظام بالكامل داخلي/إداري حاليًا.
